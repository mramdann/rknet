# Auth Fase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengganti login mock menjadi autentikasi nyata (email+password ke DB) dengan session, proteksi halaman, dan logout untuk admin & pelanggan.

**Architecture:** `auth.php` baru memegang session + guard + login/logout. Guard dipasang lewat rantai config (`admin-config.php`/`portal-config.php`) sehingga semua halaman ber-data otomatis terproteksi; halaman login tidak memuat config. Login pages memverifikasi kredensial dengan `password_verify()` lalu set session & redirect.

**Tech Stack:** PHP native (session, PDO, password_verify), MySQL `dbstarlite` @ 3382.

## Global Constraints

- Login admin & pelanggan via email + password; verifikasi `password_verify()` ke DB.
- Session admin & pelanggan terpisah (`$_SESSION['admin_id']` int, `$_SESSION['pelanggan_id']` string).
- Guard via config; halaman login standalone (tidak memuat config).
- Login gagal → pesan generik "Email atau kata sandi salah." (tak bocorkan field mana).
- Tanpa CSRF/registrasi/reset password (di luar lingkup).
- Kode & komentar Bahasa Indonesia. Lint tiap `.php`: `/d/WebServer/xampp82/php/php.exe -l <file>`.
- Re-import DB & verifikasi browser via PowerShell/BrowserOS (Bash ter-sandbox dari MySQL/localhost).

### Task 1: auth.php — session, login/logout, guard

Buat pustaka autentikasi bersama. Tidak browser-testable sendiri (dipakai Task 3 & 4); verifikasi = lint.

**Files:**
- Create: `auth.php`

**Interfaces:**
- Produces: `mulaiSesi()`, `loginAdmin(int $id)`, `loginPelanggan(string $id)`, `idAdminSaatIni(): ?int`, `idPelangganSaatIni(): ?string`, `wajibLoginAdmin()`, `wajibLoginPelanggan()`, `logoutAdmin()`, `logoutPelanggan()`. Guard me-redirect ke `login.php` (relatif terhadap folder pemanggil) lalu `exit`.

- [ ] **Step 1: Buat `auth.php`**

```php
<?php
// auth.php — sesi, login/logout, dan guard untuk admin & pelanggan.

function mulaiSesi(): void
{
    if (session_status() !== PHP_SESSION_ACTIVE) {
        session_start();
    }
}

function loginAdmin(int $id): void
{
    mulaiSesi();
    $_SESSION['admin_id'] = $id;
}

function loginPelanggan(string $id): void
{
    mulaiSesi();
    $_SESSION['pelanggan_id'] = $id;
}

function idAdminSaatIni(): ?int
{
    mulaiSesi();
    return isset($_SESSION['admin_id']) ? (int) $_SESSION['admin_id'] : null;
}

function idPelangganSaatIni(): ?string
{
    mulaiSesi();
    return $_SESSION['pelanggan_id'] ?? null;
}

function wajibLoginAdmin(): void
{
    if (idAdminSaatIni() === null) {
        header('Location: login.php');
        exit;
    }
}

function wajibLoginPelanggan(): void
{
    if (idPelangganSaatIni() === null) {
        header('Location: login.php');
        exit;
    }
}

function logoutAdmin(): void
{
    mulaiSesi();
    unset($_SESSION['admin_id']);
}

function logoutPelanggan(): void
{
    mulaiSesi();
    unset($_SESSION['pelanggan_id']);
}
```
